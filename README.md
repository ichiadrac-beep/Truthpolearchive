## Restore this version

```bash
git clone https://github.com/ichiadrac-beep/Truthpolearchive.git
cd Truthpolearchive
git checkout restore-2026-08-25-pole-x-live
npm install
npm run dev
```

On GitHub you can also open **Code → Tags → `restore-2026-08-25-pole-x-live`** and download the ZIP. That snapshot stays even if `main` changes later.
