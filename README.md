# TRUTHPOLE — The Archive

A classified desk for UAP files: sightings on a world map, conspiracy files, ancient contact, live X-Files, and The Pole.

Current snapshot: Archive globe (145 cases). Conspiracy (112 files) and Ancient (119 sites) are searchable lists — map stays on Archive.

## Run locally

```bash
npm install
npm run dev
```

Then open the app on port 8080.
